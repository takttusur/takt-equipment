# Доменная логика и классы

Тут нужно создать сущность - Заявка на снаряжение (EquipmentRequest). 
Эта сущность должна включать в себя следующие свойства:
- Идентификатор заявки (ID) тип данных guid
- Запрашиваемое снаряжение (пока просто текстовое описание) (RequestText)
- Дата когда нужна снаряга 
- Дата когда планируется вернуть снаряжение (может быть null)
- Дата создания заявки (CreatedAt)
- Дата обновления заявки (UpdatedAt)
- Статус заявки (Status - нужно сделать enum с возможными статусами: New, Approved, Issued, Returned, Rejected)
- Идентификатор пользователя который создал заявку (UserId - тип данных guid)
- Идентификатор пользователя который выдал снаряжение (IssuedByUserId - тип данных guid, может быть null)
- Идентификатор пользователя который принял снаряжение назад (ClosedByUserId - тип данных guid, может быть null)
